# Ramitha R Rao — Data Science Portfolio

A responsive personal portfolio built with HTML, CSS and JavaScript.

## Files

- `index.html` — portfolio content
- `style.css` — responsive design and theme
- `script.js` — mobile menu and theme toggle
- `assets/` — place your resume/profile image here

## Run locally

Open `index.html` in a browser, or use VS Code Live Server.

## Deploy on Vercel

1. Create a GitHub repository.
2. Upload all files in this folder.
3. Go to Vercel and import the GitHub repository.
4. Framework Preset: **Other**
5. Build Command: leave empty.
6. Output Directory: leave empty.
7. Deploy.

No backend or build process is required.
